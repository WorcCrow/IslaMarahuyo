Isla Marahuyo — update log

One page per change to the Roblox place, newest first. Each page says what was asked, what changed and why, every script and instance touched, how it was tested and what is still unverified. From 2026-09-27 on, each page also has screenshots (tool: _tools/Capture-Studio.ps1). Older history lives in ../backups/.
